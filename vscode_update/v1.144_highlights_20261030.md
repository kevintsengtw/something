# Visual Studio Code 1.144 更新重點

- 版本：1.144.0（Stable）
- 發行日期：2026 年 10 月 28 日
- 原文連結：https://code.visualstudio.com/updates/v1_144

---

本版七大主軸為：跨環境的 session 延續性、Copilot Fusion 與模型比較、圖片產生、Computer use、工作集檢閱、Assisted permissions，以及自訂項目市集與 Copilot connectors。

- **Session 延續性**：Cloud session 不需本機上線即可執行 Copilot 任務；新增 Remote Environments 對話方塊集中管理遠端；Cloud Automations（預覽，`chat.automations.cloud.enabled`）在電腦關機時仍依排程或存放庫事件執行；發布 Agent Host Protocol v1.0。
- **Copilot Fusion（正式推出）**：由 Copilot 自動選擇並協調模型，分 Standard／High／Max 強度層級；11 月 30 日前付費方案享 30% 折扣。
- **模型比較**（`sessions.chat.compareAgents.enabled`）：Agents 視窗新 session 預設啟用，並支援無專案及本機／空的存放庫。
- **圖片產生（預覽）**（`chat.copilot.imageGeneration.model`）：以 GPT Image 2.5 Flare 在聊天中產生與修改圖片，可選加浮水印。
- **Computer use（實驗性）**（`chat.agentHost.computerUse.enabled`）：agent 可看見並操作 macOS／Windows 上的桌面應用程式，以 `/computer on|off` 切換。
- **工作集（實驗性）**（`chat.editor.workingSet.enabled`）：Copilot harness 的檔案編輯可在編輯器中逐項 Keep 或 Undo。
- **Assisted permissions（正式推出）**：以 LLM 評估工具呼叫風險，低風險自動核准，其餘仍需確認。
- **Copilot connectors 與市集（預覽）**：以 GitHub 管理的 MCP 伺服器連接 Slack、Notion 等服務；Browse 成為 Customizations 新首頁，集中探索 skill 與外掛。

其他更新：

- **版本回顧**：彙整近期成果，包括 Agent Host、AHP、Copilot harness 預設、Claude Code／Codex harness、canvas、全新 Markdown 編輯器與 UI 翻新。
- **Agent 整合**：Canvas 可在 Agent Customizations 編輯器中管理，並可從 **Add Context (+)** > **Canvas...** 開啟。
- **Agents**：Session 撰寫器先選環境、可無工作區聊天、可收合為圖示並支援快速鍵（實驗性）；Copilot harness 支援 Copilot Memory；worktree 清理可依工作區篩選並在磁碟不足 5 GB 時提示；擴充功能可在 Agents 視窗中啟用。
- **Agent 自訂**：自訂 agent 的 `model`／`tools`／`skills` 自動完成與驗證；無 `target` 時依作用中 harness 提供提示；外掛與自訂頁面的深層連結；`/plugin`、`/mcp`、`/skills` 斜線命令。
- **Session 管理**：聊天可在 session 間拖曳移動（預覽）；巢狀 session 可選不同工作區；快速聊天支援巢狀 session；session 群組可自訂圖示與顏色。
- **語音模式（實驗性）**：可掌握 session 情境回答問題，工作中的口語指示以引導送出；工具核准支援 25 種語言。
- **Issue 回報工具**：單頁表單、可附加檔案、可提交到其他存放庫。
- **終端機**：Windows 上終端機命令開啟的對話方塊改顯示在 VS Code 前方。
- **企業**：受限制的權限模式改為停用並說明；組織可管理預設模型、Fusion 層級與權限；設定載入進度改在聊天內顯示。
- **GitHub Pull Requests**：透過 GitHub API 更新堆疊式 PR，並提示可建立堆疊。
- **擴充功能撰寫**：`vsce publish --oidc` 支援以 OIDC 與 Trusted Publishing 從 GitHub Actions 發布，免存 PAT。
- **棄用**：無。

**總結**：本版讓 agent 工作能跨本機、遠端與雲端持續進行，以 Copilot Fusion 與模型比較協助選模型，並透過工作集與 Assisted permissions 強化對變更與工具呼叫的掌控。
