# Visual Studio Code 1.145 更新重點

- 版本：1.145（Stable），目前更新版為 1.145.1
- 發行日期：2026 年 11 月 4 日
- 原文連結：https://code.visualstudio.com/updates/v1_145

---

本版六大主軸為：遠端 agent 的瀏覽與 canvas、同一 session 混搭 harness、本機自動化 cron 排程、agent 詳細程度、檔案排除例外，以及企業 MCP 允許清單。

- **遠端 agent 瀏覽與 canvas（預覽）**（`workbench.browser.enableRemoteProxy`、`chat.canvases.enabled`）：整合式瀏覽器透過遠端 agent host 載入頁面，可在 Agents 視窗預覽遠端開發伺服器並使用遠端 canvas。
- **混搭 agent harness（預覽）**（`chat.agentHost.multipleChatProviders.enabled`）：巢狀 session 可使用不同於父 session 的 harness，例如讓 Claude 檢閱 Copilot 的計畫；各聊天的模型、agent 與權限各自獨立。
- **本機自動化 cron 排程**：可輸入五欄位 cron 運算式（雲端自動化不支援）、選用工作區自訂 agent，已停用項目集中收合。
- **Agent 詳細程度（實驗性）**（`chat.persistentProgressVerbosity`）：View Mode 提供 Conversation／Verbose／Compact（預設）三種顯示方式。
- **檔案排除例外**（`files.exclude`、`search.exclude`）：樣式前加 `!` 可讓已排除資料夾中的特定檔案保持可見、可搜尋。
- **企業 MCP 允許清單**：`allowedMcpServers` 優先於僅限登錄存取，未發布到登錄的伺服器也能核准執行（僅限 VS Code 啟動的伺服器）。

其他更新：

- **Agents**：canvas 可釘選到側邊欄（實驗性）；Copilot harness 持續為預設並新增從 Local 轉換的指南；工作集支援 WSL／Dev Containers／SSH 及平行編輯追蹤（實驗性）；必要沙箱無法執行時，警告橫幅會說明原因並提供疑難排解。
- **聊天**：長聊天效能改進；內嵌附件膠囊（實驗性，`chat.inlineAttachments.enabled`）；可用 **Add Context** > **Files** 附加工作區外的檔案，沙箱下 agent 可唯讀存取。
- **MCP**：MCP app 可註冊供模型呼叫的工具。
- **編輯器**：Mermaid 子圖標題會避開邊，子圖改以外框呈現。
- **企業**：組織要求的外掛及其提供項目無法解除安裝，並顯示說明。
- **GitHub Pull Requests**：時間軸事件更多、PR 描述範本支援 issue 變數、堆疊 PR 時提示停用自動合併。
- **擴充功能撰寫**：Timeline API 正式定案。
- **趣味**：以 `/vscode-pet` 叫出 Blobby，玩跳躍遊戲（實驗性）。
- **棄用**：Local harness 移除 `#installExtension`、`#runCommand`、`#newWorkspace`／`#new`、`/new` 與相關設定；即將棄用：無。
- **重要修正**：組織關閉 Claude／Codex 後新聊天改回退預設 harness；MCP 登錄原則重新整理失敗時保留最後已知原則。

**總結**：本版讓遠端 agent session 更接近本機體驗，並以混搭 harness、cron 自動化與可調的聊天詳細程度提升 agent 工作的彈性，同時強化企業對 MCP 與外掛的管理。
