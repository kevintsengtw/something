# VS Code 1.142 更新重點

**版本：** 1.142｜**發行日期：** 2026 年 10 月 14 日
**原文：** https://code.visualstudio.com/updates/v1_142

---

本版五大主軸為 Canvas 協作、移動聊天、Markdown 編輯器、企業權限管理與重新設計的模型選擇器：

- **Canvases（預覽）**（`chat.canvases.enabled`）：在聊天旁開啟互動式 canvas（例如 Kanban），你與 agent 共同檢視、更新同一個成品；適用於使用 Copilot harness 的本機 session，可用 `/create-canvas` 建立 canvas 擴充功能。
- **在資料夾與 worktree 之間移動聊天**：在 Agents 視窗請 agent 把目前聊天移到另一個資料夾或新的 Git worktree，對話歷程完整保留；適用於 Codex harness 或 Interactive 模式下的 Codex。
- **Markdown 編輯器**：編輯模式逐行對應原始碼，並新增貼上圖片、以 F2 重新命名檔案連結、大綱與階層連結整合，以及程式碼區塊複製按鈕。
- **企業權限管理**：組織設定 `permissions` 或 `sandbox.enabled` 時，Local 聊天會自動移至 Copilot Agent Host 以強制執行原則（可用 `vscode.temporaryDefaultToLocalHarness` 暫時保留 Local）；並可允許 **Assisted** 同時封鎖 **Allow All**。
- **重新設計的模型選擇器**：以分頁區分 Copilot 與 BYOK 模型，滑鼠停留即可調整思考層級與上下文視窗大小。

其他更新：

- **Copilot harness**：逐步推出為新 session 的預設 harness，並重新加入唯讀的 **Ask** 內建 agent。
- **Session 範圍版面配置（實驗性）**（`sessions.experimental.layoutScope`）：可選擇每個 session 要記住多少版面配置。
- **Agents 視窗面板對齊**：底部面板可選 `Center` 或 `Justify`。
- **聊天標題顯示 harness 名稱**（如 Copilot、Codex）。
- **停止背景 shell**：可從 **Background Shells** 停止 agent 在目前請求中執行的 shell。
- **BYOK 自訂端點**：無狀態 Responses API 可設 `"statefulResponses": false` 傳送完整歷程。
- **合併文件醒目提示**（`editor.occurrencesHighlightFromAllProviders`）。
- **Python**：Python Environments 擴充功能修正環境探索、直譯器選擇與終端機啟用，並改善 `uv` 支援。
- **Windows 數值原則**支援 DWORD／QWORD。
- **GitHub Pull Requests 擴充功能**：預設啟用堆疊式 PR，可更新無衝突的本機 PR。
- **棄用**：Local harness 的 Windows 沙箱（改用 Agent Host session）。

**總結**：本版以 Canvas 與移動聊天擴展與 agent 協作的方式，並強化 Markdown 編輯、模型切換與企業對 agent 權限的控管。
