# VS Code 1.146 更新重點

**版本：** 1.146｜**發行日期：** 2026 年 11 月 11 日
**原文：** https://code.visualstudio.com/updates/v1_146

---

本版五大主軸為 Local harness 淘汰、Inbox 模式、模型比較、聊天視窗與 Agents 視窗擴充功能：

- **Local harness 淘汰**：自本版起凍結功能，2027 年 2 月移除；`vscode.temporaryDefaultToLocalHarness` 也將一併移除，請改用 Copilot harness（自 1.143 起已為預設）。
- **Inbox 模式（實驗性）**（`sessions.list.inboxEnabled`）：在 Agents 視窗以單一檢視列出需要關注的 session，其他可 Dismiss、Put on Hold 或 Snooze。
- **模型比較改進（預覽）**（`sessions.chat.compareAgents.tools.enabled`）：不選工作區也能評審與綜合、可比較 Copilot Fusion，並可讓 agent 自動執行比較（實驗性）。
- **聊天視窗（預覽）**（`sessions.chatWindows.enabled`）：聊天可開在獨立視窗，自由排列聊天、編輯器與終端機；Stable 預設關閉。
- **Agents 視窗中的擴充功能（實驗性）**：不離開 Agents 視窗即可從 Marketplace 搜尋、安裝與解除安裝，並在安裝前提示不支援的功能。

其他更新：

- **Agents 視窗**：sessions 清單內嵌動作可直接修正檢查與處理審查意見（實驗性）；Canvas 新增權限提示並改善還原與重新連線（預覽）；可設定這台電腦透過 GitHub Environments 或 Dev Tunnels 共用（實驗性）；Copilot harness 支援虛擬存放庫。
- **聊天**：Copilot CLI 輸入 `/code` 可將 session 移到 VS Code 繼續（實驗性）；背景傳送（Ctrl+Enter）快速鍵可自訂。
- **MCP**：支援 SEP-2640 Skills over MCP（預覽），MCP 伺服器可自動提供 skills。
- **信任與安全性**：權限提示改為針對特定網域、命令與目錄；沙箱可遮罩環境變數，只對指定 HTTPS 主機注入真值；聊天輸入框顯示沙箱狀態。
- **編輯器**：Mermaid 12（含使用案例圖）；Integrated Browser 可複製本機 HTML 的 `file://` 位址；Welcome 頁面顯示鍵盤焦點外框。
- **企業**：Copilot session 遵循 Proxy 設定（含 PAC、Kerberos）；`communication.support.url` 可為原則限制加上 Contact Admin 連結；`strictPluginOnlyCustomization` 可封鎖獨立 canvas 擴充功能。
- **修正**：agent 編輯指標不再把未變更的文字計為新增或刪除。
- **棄用**：Local harness（2027 年 2 月移除）；即將淘汰項目：無。

**總結**：本版正式淘汰 Local harness、全面轉向 Copilot harness，並以 Inbox 模式、聊天視窗與 agent 自動化模型比較，讓多 session 的 agent 工作更容易掌握。
