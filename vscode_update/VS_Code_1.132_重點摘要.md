# Visual Studio Code 1.132 (Insiders) 版本重點摘要

**版本：** 1.132（Insiders）
**最後更新：** 2026 年 8 月 3 日
**原文：** https://code.visualstudio.com/updates/v1_132

> 本發行說明涵蓋 VS Code 的 Insiders 組建，並會隨新功能加入而持續演進。

---

本版為 Insiders 滾動式更新記錄（7/24–7/31），依主題整理如下：

## 一、語音模式與聽寫（本版最大宗）

- **重新設計的環境光暈**：為語音模式和聽寫加入重新設計、感知佈景主題的環境光暈，以區分聆聽和說話狀態（7/31）
- **數字格式化**：支援將聽寫的數字格式化為數字符號（7/31）
- **本地化語音預覽**：語音模式引導卡片加入本地化語音預覽（7/31）
- **多語言裝置端聽寫**：支援使用 Nemotron 3.5 語音轉文字模型的多語言裝置端聽寫（7/31）
- **手動安裝聽寫模型**：新增 **Chat: Install Dictation Model from Local Package...** 命令，可手動安裝裝置端聽寫模型（7/30）
- **設定橫幅**：首次使用語音模式時顯示設定選項的橫幅（7/29）
- **自訂聽寫與語音模式**：支援以 `dictation.md` 和 `voice.md` 檔案自訂，存放於使用者設定檔（`~/.copilot/dictation.md`、`~/.copilot/voice.md`）或受信任工作區的 `.github` 資料夾（7/28）
- **修正**：修正語音轉文字模型下載或載入期間取消聽寫無效的問題（7/24）

## 二、整合式瀏覽器

- **元素註解**：支援在整合式瀏覽器中為元素加上註解（7/31）
- **合併附件**：支援將同一瀏覽器元素的多個附件合併為單一項目，包含其文字內容與截圖（7/27）

## 三、聊天與終端機

- **動態重新換行**：聊天中的行內終端機命令輸出可在您調整面板或側邊欄大小時，動態重新換行以符合容器寬度（7/31）
- **PowerShell 語法解析**：評估 Agent Host 終端機自動核准規則時，支援以專用文法解析 PowerShell 語法（7/30）
- **終端機分頁標題顯示 `~`**：使用 `${cwd}` 變數的終端機分頁標題可顯示 `~` 而非完整家目錄路徑，減少視覺雜訊（7/29）

## 四、編輯器體驗

- **`code serve-web` 支援 `--enable-proposed-api`**：讓在 `package.json` 中宣告 `enabledApiProposals` 的擴充功能在瀏覽器中正確啟動，與現有桌面行為一致（7/29）
- **手動摺疊範圍移除改善**：**Remove Manual Folding Ranges** 命令現在僅移除游標位置最內層的手動摺疊範圍，而非所有與游標相交的手動範圍（7/29）
- **Markdown 預覽複製程式碼區塊**：每個圍籬程式碼區塊在懸停時顯示複製按鈕（7/28）
- **分頁右鍵選單新增儲存**：編輯器分頁右鍵選單加入 **Save** 和 **Save As**，可直接從分頁儲存已修改的檔案，無需開啟 Explorer 或檔案選單（7/27）
