# VS Code 1.143 更新重點

**版本：** 1.143｜**發行日期：** 2026 年 10 月 19 日
**原文：** https://code.visualstudio.com/updates/v1_143

---

本版五大主軸為 Copilot harness 成為預設、比較模型、回收 worktree 儲存空間、裝置端模型與多檔案差異檔案清單：

- **Copilot harness 成為預設**：新 session 預設使用建構於 Copilot SDK 的 Copilot harness，可在編輯器與 Agents 視窗間存取；另推出初步的檔案層級工作集 **Keep**（`chat.editor.workingSet.enabled`，實驗性）。
- **比較模型結果（預覽）**（`sessions.chat.compareAgents.enabled`）：在 Agents 視窗以多個模型／harness 平行執行同一任務，可由 Judge 模型評分推薦，再以 **Synthesize** 合併想法。
- **回收 worktree 儲存空間（實驗性）**（`chat.agentSessions.sessionStorageCleanupSuggestion.enabled`）：以 **Chat: Open Worktree Cleanup** 檢視並清除非作用中 session 的 worktree，可還原重建，作用中與釘選的 session 受保護。
- **裝置端模型（實驗性）**（`chat.copilot.localModel.enabled`）：透過 llama.cpp 在本機執行 MAI Code 1.1 Flash，不使用 AI 點數；需 96 GB 以上 GPU 記憶體的 NVIDIA GPU。
- **多檔案差異檔案清單（實驗性）**（`multiDiffEditor.experimental.fileList`）：在差異檢視旁以清單或樹狀顯示變更檔案與狀態字母，點選即跳轉。

其他更新：

- **Agents 視窗**：Branch／Session／Last Turn Changes 也可捨棄變更；空白側邊窗格列出分頁捷徑；Session 活動列（實驗性）；空白 Files 分頁可搜尋與新增檔案（實驗性）；大型聊天開啟速度大幅提升。
- **語音模式 BYOK（預覽）**：可用自己的 OpenAI 金鑰與即時模型。
- **沙箱**：可管理沙箱 CA 憑證信任（Windows／macOS）；原則允許時可針對單一 session 關閉終端機沙箱。
- **聊天**：從 **New Chat (+)** > **Canvas** 開啟 canvas（預覽）；可查看與停止已分離背景 shell 的輸出。
- **診斷醒目提示上限**：每檔案從 500 提高到 5,000，並在語言狀態指示器顯示上限警告。
- **企業**：OTel 動態標頭（`telemetry.headersProvider`）、受管理模型預設值、原則要求 Copilot 時說明 Local 為何停用、組織設定載入等待、受管理工具核准提示減少、受管理外掛自動安裝、既有 Claude／Codex session 可用 Copilot 繼續。
- **安裝設定**：VS Code 安裝程式可一併安裝 GitHub Copilot CLI（Windows／Linux／macOS）。
- **棄用**：無。

**總結**：本版以 Copilot harness 為預設核心，並新增多模型比較、本機模型與 worktree 清理，同時強化 agent 工作檢閱、沙箱信任與企業管控。
